## 6. 完善过程中的缺陷修复

| 缺陷 | 位置 | 修复 |
| --- | --- | --- |
| `httpx.SSLError` 属性不存在 | `app/scrape/validator.py` | 改用 `ssl.SSLError` 分类，`_classify_connect` 依据 `__cause__` 判定 |
| FastAPI `Optional[BackgroundTasks]` 参数解析失败 | `app/web/api.py` | 改为 `BackgroundTasks = None` + type ignore |

| **跨 URL 误取内容**：`_crawl_one` 取 `candidates[0]`，多候选场景两 URL 均解析为首条 → 误判重复、任务错标 partial | `app/scrape/service.py` | 过滤与目标 URL 一致的候选后再取首条（FR-24 语义） |
| ruff 8 项告警（import 排序/未用导入/嵌套 with/B008/RUF015） | 各文件 | 自动修复 5 项 + 手动修复 3 项（FastAPI Body 惯用法加 noqa） |
